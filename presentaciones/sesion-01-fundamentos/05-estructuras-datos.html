Pieza 1 · Variables primitivas

Un nombre para guardar un dato

En Python no hay que avisar de qué tipo es una variable — Python lo descubre solo. Los tipos básicos:

  • int — números enteros (5, -3)
  • float — números con decimales (4.5)
  • str — texto, entre comillas ("Ana")
  • bool — verdadero o falso (True / False)
nombre_estudiante = "Ana"
nota = 4.5
aprobado = True

print(type(nombre_estudiante))  # <class 'str'>

Nombrar variables bien es parte del oficio (clean code):

  • 1nombre — no puede empezar con un número (error de sintaxis).
  • class, for, if, True — palabras reservadas del lenguaje, no se pueden usar como nombre.
  • x, dato1 — válidos, pero poco descriptivos: nadie sabe qué guardan a simple vista.
  • nota_estudiante — snake_case, describe exactamente qué contiene. Así se nombra en este curso.

type(...) es la herramienta que van a usar constantemente para "preguntarle" a Python qué tiene guardado.

Menciona que Python tiene una lista fija de palabras reservadas (unas 35) — no hace falta memorizarlas, el editor las resalta de otro color automáticamente.

🧬
Antes de indexar

Un string no es "un string" — es un array de caracteres

Por dentro, Python guarda cada string como una secuencia ordenada de caracteres, cada uno con su propia posición — empezando en 0, no en 1.

A
0
n
1
a
2

Por eso nombre[0] te da la primera letra — es exactamente el mismo mecanismo que van a usar con listas en un momento.

Este es el puente conceptual antes de indexar — si esto queda claro, la siguiente diapositiva (indexación y slicing) se siente obvia, no arbitraria.

🔁
Un problema muy común con datos reales

Casting: convertir entre tipos

Los datos reales casi nunca llegan en el tipo que necesitas — un número puede llegar como texto. Para convertir, usamos int(...), float(...), str(...).

nota_texto = "4.5"          # llegó como string
nota_numero = float(nota_texto)  # ahora sí se puede sumar/comparar

Este es, casi siempre, el primer error que vas a depurar cuando trabajes con datos reales: algo que "se ve" como número pero Python lo trata como texto.

Esto conecta directo con lo que van a ver en los notebooks de nivel medio/difícil: valores faltantes y columnas "sucias" que llegan como texto.

Pieza 2 · Strings

Indexar y recortar texto

Un string se puede "recorrer" por posición (indexación) y "recortar" (slicing) — igual que una lista.

nombre = "Ana Gomez"

nombre[0]      # 'A'      → primera letra
nombre[0:3]    # 'Ana'    → primeras 3 letras
nombre[-1]     # 'z'      → última letra

El slicing [inicio:fin] reaparece idéntico en listas — vale la pena remarcar el paralelismo.

🧹
Pieza 2 · Strings

Métodos para limpiar texto

Un método es una función que "pertenece" a un dato y se llama con un punto: dato.metodo(). Los strings traen varios métodos incorporados — estos son los que más van a usar:

  • .strip() — quita espacios sobrantes al inicio/final.
  • .upper() / .lower() — cambian mayúsculas/minúsculas.
  • .title() — Primera Letra De Cada Palabra En Mayúscula.
  • .replace(a, b) — reemplaza texto.
sucio = "  ana gomez  "
limpio = sucio.strip().title()
# limpio → "Ana Gomez"

Estos son, literalmente, los mismos métodos que vas a usar la próxima sesión con .str en Pandas — sobre una columna entera en vez de un solo texto.

Esta es la conexión más importante de la diapositiva con la siguiente sesión — que quede clara la idea de "lo mismo, pero aplicado a una tabla completa".

Pieza 3 · Listas

Varios valores, en orden

Una lista guarda varios valores en orden, entre corchetes [ ].

notas = [3.5, 4.0, 2.8, 5.0, 4.2]

len(notas)              # 5      → cuántos elementos
sum(notas)              # 19.5   → suma
sum(notas) / len(notas) # 3.9   → promedio
max(notas), min(notas)    # 5.0, 2.8

Este es exactamente el bloque que abre el Ejercicio 3 de los tres notebooks — len, sum, max, min son las cuatro funciones que más van a repetir hoy.

Pieza 3 · Listas

Recorrer y filtrar con for

Para revisar cada elemento uno por uno, usamos un for. Combinado con un if, podemos filtrar o contar.

notas = [3.5, 4.0, 2.8, 5.0, 4.2]
aprobados = 0

for nota in notas:
    if nota >= 3.0:
        aprobados += 1

print(aprobados)  # 4

El nivel medio de los notebooks (recorrer, filtrar y contar) es exactamente este patrón, un poco más largo.

Menciona en voz alta: en clases futuras vamos a ver por qué este mismo patrón, hecho con miles de datos, puede ser lento — y cómo Pandas/NumPy lo resuelven por dentro. Hoy solo lo nombras, no hay que profundizar.

Pieza 4 · Diccionarios

Acceder por nombre, no por posición

Un diccionario guarda datos con una "etiqueta" (llave) para cada valor, entre llaves { }.

estudiante = {
    "nombre": "Ana",
    "nota": 4.5,
}

estudiante["nombre"]  # "Ana"

# f-string: arma un mensaje con variables adentro
mensaje = f"{estudiante['nombre']} tiene una nota de {estudiante['nota']}"

El f-string suele generar dudas la primera vez — vale la pena escribirlo en vivo y mostrar qué pasa si se te olvida la f al inicio.

🎯
Uniendo todo

Una lista... de diccionarios

¿Qué se puede guardar dentro de una lista?

Lo que sea — incluyendo diccionarios. Así es como casi siempre se ven los datos reales antes de que existan herramientas como Pandas: una lista de registros, cada uno un diccionario.

grupo = [
    {"nombre": "Ana",   "nota": 4.5},
    {"nombre": "Luis",  "nota": 2.7},
    {"nombre": "Marta", "nota": 3.0},
]

for estudiante in grupo:
    estado = "Aprobado" if estudiante["nota"] >= 3.0 else "No aprobado"
    print(f"{estudiante['nombre']}: {estado}")

Cada fila de un DataFrame de Pandas es, por dentro, básicamente esto: un diccionario dentro de una lista.

Esta es la diapositiva puente hacia la próxima sesión — no hace falta profundizar en Pandas hoy, solo plantar la idea.
